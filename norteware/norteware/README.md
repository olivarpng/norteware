# NORTE WEAR BR

Landing page streetwear da loja [@nortewearbr](https://www.instagram.com/nortewearbr/).

Site estático: HTML + CSS puro, sem build e sem dependências. Fontes via Google Fonts (Anton e Space Mono).

## Rodar local
Abra o `index.html` no navegador.

## Publicar no GitHub Pages
Settings → Pages → Source: `main` / `(root)`.

## Personalizar
- Cor de destaque: troque `#A855F7` em todo o `index.html`.
- Fotos, preços e nomes das peças: procure os textos entre colchetes, como `[FOTO DA PEÇA]` e `[PREÇO]`.
